# Transmission Site vitrine — CTA vers la création BIMA

Date : 16 août 2026  
Application : https://bima-app-sigma.vercel.app/

## Changement terminé

BIMA possède maintenant une URL stable qui ouvre directement le formulaire de création d’une sortie :

https://bima-app-sigma.vercel.app/creer

L’utilisateur n’a plus besoin d’arriver sur l’accueil de l’application puis de cliquer une seconde fois sur « Créer une sortie ».

## Bénéfice utilisateur

- Un seul clic entre la landing page et le formulaire.
- Moins de friction au moment principal de conversion.
- Le bouton retour du navigateur permet de revenir normalement à l’écran précédent.
- L’URL peut être utilisée dans tous les CTA de la vitrine et dans les campagnes externes.

## Mise à jour obligatoire de la vitrine

Pour tous les CTA destinés à lancer la création :

- conserver le libellé validé **« Je crée ma sortie »** ;
- remplacer le lien actuel par **https://bima-app-sigma.vercel.app/creer** ;
- ouvrir le lien dans le même onglet ;
- appliquer le changement aux versions desktop et mobile, ainsi qu’au CTA mobile fixe s’il existe.

## Vérification demandée

Après publication de la vitrine :

1. cliquer sur chaque CTA principal ;
2. vérifier que le formulaire « On organise quoi ? » apparaît directement ;
3. tester le retour navigateur vers la landing page ;
4. refaire le contrôle sur mobile.

## À ne pas modifier

- Ne pas remplacer le CTA par une formulation SaaS générique.
- Ne pas ajouter d’étape d’inscription ou d’écran intermédiaire.
- Ne pas utiliser uniquement l’URL de l’accueil `https://bima-app-sigma.vercel.app/` pour ces CTA.

## Suggestion facultative

Ajouter des paramètres UTM au lien uniquement si la vitrine dispose déjà d’un plan de mesure cohérent. L’URL fonctionnelle de base doit rester `/creer`.
